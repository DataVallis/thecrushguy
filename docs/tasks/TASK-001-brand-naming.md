Deliver a shortlist so the owner can pick the brand name and domain.

## Steps
1. Generate 40+ candidates across the directions in `05-BRAND.md`.
2. Filter by criteria 1–8; drop anything explicit or trademark-confusable.
3. For top 15: check domain availability and price (.com first, then .ai/.co/.app), record registrar + price + date.

5. Social handle check (X, Instagram, TikTok, Reddit, YouTube, Telegram).
6. Meaning check in DE, FR, ES, IT, PT, PL, NL, SL, JA, KO.
7. Score table → top 3 with rationale.
