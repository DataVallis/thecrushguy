Project: The Crush Guy — independent review directory of AI companion apps (SFW public pages, affiliate-funded).

## Hard rules
- **Never invent data.** No search volumes, difficulty scores or traffic numbers unless a page you opened in this run states them — then record the URL. Do not estimate volumes yourself.
- Open only SFW pages. If a result is an explicit adult site, record domain + URL + title from the search result only and do not open it.
- Record exactly what you saw: URL, title, rank position, date checked 2026-10-29. Search results come from the WebSearch tool (not a logged-out Google SERP) — say so; do not claim they are Google rankings.
- Write the output file with the Write tool as valid JSON, then reply with a 5-line summary only.
